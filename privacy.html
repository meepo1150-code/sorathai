ความเป็นส่วนตัว

นโยบายความเป็นส่วนตัวของ Sorathai อธิบายการประมวลผลวันเกิด การเก็บโปรไฟล์ใน localStorage การล้างข้อมูล และทรัพยากรภายนอก

ข้อมูลวันเกิดและโปรไฟล์

วันเกิดที่กรอกถูกประมวลผลด้วย JavaScript ในเบราว์เซอร์เพื่อสร้างคำอ่าน Sorathai ไม่มีระบบบัญชีหรือฐานข้อมูลโปรไฟล์ในเว็บไซต์รุ่นนี้ และโค้ดของ Sorathai ไม่ส่งวันเกิดหรือโปรไฟล์ไปยังเซิร์ฟเวอร์ของ Sorathai

เมื่อเบราว์เซอร์อนุญาต ระบบเก็บข้อมูลที่ key sorathai.profile.v1 ใน localStorage บนอุปกรณ์นี้ ข้อมูลประกอบด้วยเวอร์ชัน วันเกิด ค่าเชิงสัญลักษณ์ รายชื่อศาสตร์ที่เปิด และมุมคำอ่านล่าสุด URL ของหน้าคำอ่านอาจมีวันเกิดในพารามิเตอร์ dob; ผู้ที่เห็นลิงก์ ประวัติเบราว์เซอร์ หรือหน้าจออาจเห็นค่านี้ได้

การเปลี่ยน ล้าง และรีเซ็ต

ปุ่ม “เปลี่ยนวันเกิด” กลับไปยังแบบฟอร์ม แต่ยังไม่ลบโปรไฟล์ ส่วนปุ่ม “ล้างวันเกิด” บนหน้าแรกเรียกการลบ key ของ Sorathai จาก localStorage แล้วเริ่มใหม่ การล้างข้อมูลเว็บไซต์หรือ localStorage ผ่านการตั้งค่าเบราว์เซอร์ให้ผลเช่นเดียวกัน การล้าง Sorathai ไม่ลบประวัติ URL ดาวน์โหลดภาพ หรือสำเนาที่แชร์ไว้; ต้องจัดการสิ่งเหล่านั้นแยกต่างหาก

หาก localStorage ถูกปิด เต็ม หรือเข้าไม่ได้ คำอ่านหลักยังทำงานได้ใน session ปัจจุบัน แต่โปรไฟล์อาจไม่ถูกเรียกคืนในการเข้าครั้งถัดไป

ความฝัน

ข้อความความฝันถูกตีความด้วยชุดข้อมูลและ JavaScript ภายในเว็บไซต์รุ่นนี้ โดยไม่มีการส่งไปยังบริการ AI ภายนอก โปรดหลีกเลี่ยงการใส่ข้อมูลส่วนบุคคลที่ไม่จำเป็น เพราะข้อความอาจปรากฏใน URL และประวัติเบราว์เซอร์

ทรัพยากรจากบุคคลที่สาม

  • Google Fonts — เบราว์เซอร์อาจเชื่อมต่อกับ Google เพื่อขอไฟล์ฟอนต์และเปิดเผยข้อมูลคำขอมาตรฐาน เช่น IP address และ user agent; หากถูกบล็อก เว็บไซต์ใช้ system-font fallback และข้อความยังปรากฏทันทีด้วย display=swap
  • html2canvas จาก cdnjs — โหลดเฉพาะหน้าที่มีการส่งออกภาพ เพื่อแปลงการ์ดบนหน้าจอเป็นภาพในเบราว์เซอร์ หากโหลดไม่ได้ คำอ่านและการนำทางยังใช้ได้และระบบแจ้งว่าการสร้างภาพไม่พร้อมใช้งาน

Repository อาจมีตำแหน่งโฆษณาสำรองใน markup แต่รุ่นนี้ไม่โหลดสคริปต์โฆษณา การเปลี่ยน dependency หรือการเผยแพร่จริงควรทบทวนนโยบายนี้อีกครั้ง
